# 教会结构与小组负责人指南

## 从这里开始

教会结构描述普通归属与关怀背景。它不会自动授予负责人权限、同工权限、服事或管理权。

只有当你的账号显示“我负责的单位”时，才使用该入口。这表示系统中已经有明确路径，使你至少可以维护一个单位。

## 常见任务

1. 打开账号菜单。
2. 如果可以看到“我负责的单位”，请选择它。
3. 选择你负责的单位。
4. 查看该单位页面显示的成员与同工信息。
5. 只有当页面提供添加、结束、批准、拒绝或记录操作时，才执行对应动作。

## 你可以做什么

- 查看你有权维护的单位。
- 在当前流程允许时维护小组归属。
- 查看并处理你负责小组的待审加入申请。
- 当某项变更超出你的委派页面时，请让教会同工使用更完整的结构设置与检查页面。

## 怎么操作

### 查看单位

打开“我负责的单位”并选择单位。修改前先确认单位路径、当前成员和同工信息。

### 添加成员

添加成员时，只对符合条件且未分配的用户使用添加操作。页面会阻止已有有效主要归属的用户。

### 结束成员归属

需要结束成员当前归属时，在单位页面使用结束操作。这只结束归属，不删除用户账号。

### 成员申请

被委派的小组负责人在“我负责的单位”下的对应小组页面查看待审申请。只有当你拥有适用的委派管理访问权限时，页面才会显示批准或拒绝操作。

只有当申请的小组正确，且用户没有其他有效主要归属时，才批准。已有有效主要归属的冲突仍会被阻止。本指南不表示这里有转组流程。

同工可以另外使用全局的同工成员申请队列。

### 同工 / 成员信息

单位页面显示的信息用于关怀和维护。不要把成员名单当作服事名单或权限名单。

## 这不代表什么

- 成员归属不是负责人权限。
- 成员归属不是服事。
- 教会结构单位不是事工团队排班。
- “我负责的单位”的归属维护不会创建服事安排、查经角色或同工权限。
- 不要建立假的“未分配”单位。未分配是一种候选状态，不是教会结构单位。

## 疑难处理 / 下一步

如果看不到“我负责的单位”，表示你当前没有这个委派页面。如果某位成员无法添加或批准，请检查是否已有有效主要归属，或请同工检查结构资料。
