# 服事与事工指南

## 从这里开始

当你有明确服事安排时，请使用“我的服事”。服事不会从成员归属、可见范围、同工身份或活动可见性自动推断。

“我的服事”是个人服事工作区。它帮助你查看分配给你的服事，在可确认时进行确认，并打开相关聚会、团队或查经聚会链接。

## 常见任务

1. 打开“我的服事”。
2. 查看需要留意、今日服事、本周服事、之后服事和过去服事。
3. 打开服事卡片，查看相关教会聚会或查经背景。
4. 页面提供确认操作时，按实际情况确认服事。
5. 只有在你已有相应权限时，才进入同工或团队管理页面处理排班。

## 你可以做什么

- 查看明确分配给你的教会聚会服事。
- 查看明确关联到你账号的查经服事。
- 在当前流程支持时确认服事。
- 打开相关聚会、查经、团队或排班背景链接。
- 如果你管理团队或有同工访问权限，可使用现有管理页面进行排班和检查。

## 怎么操作

### 我的服事

在可用时，从主导航打开“我的服事”。先查看需要留意的事项，再查看今日和之后的服事。需要旧记录时，使用过去事项标签。

### 确认

如果服事卡片提供确认操作，请先核对日期、时间、团队、排班状态和备注，再提交确认。确认属于“我的服事”；“日历”和“今日”可以链接到这里，但不会替你确认。

### 教会聚会服事

教会聚会服事中，打开服事卡片并查看相关聚会背景。作为成员能看到聚会，和被安排在该聚会服事，是两件不同的事。

### 查经服事

查经服事中，打开“我的服事”里的角色卡片。只有当查经角色明确关联到你的用户账号时，才会显示为你的个人服事。

### 负责人 / 同工需留意事项

需要排班或检查时，请打开对应管理页面。 “我的服事”只做提醒和汇总，不取代完整排班流程。

## 这不代表什么

- 教会结构归属是归属，不是服事。
- 可见范围不是服事。
- 活动可见性不是服事。
- 查经角色只有显示姓名但没有关联用户时，不会成为你的个人服事项。
- 长期角色或团队责任不等于某一周的聚会服事安排。
- “我的服事”必须基于明确服事资料。

## 疑难处理 / 下一步

如果你预期看到某个服事项但没有出现，请请排班同工检查你的用户账号是否明确关联到该排班或查经角色。不要用成员归属或可见范围绕过服事资料。
