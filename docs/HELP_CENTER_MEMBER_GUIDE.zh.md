# 成员指南

## 从这里开始

本网站帮助你参与日常教会生活：读经、查看今日事项、参与代祷、阅读公告、查看教会聚会、浏览活动，并维护个人资料。

你通常可以先打开“今日”。“今日”是日程与行动提醒，不是系统里所有内容的完整列表。

## 常见任务

1. 打开“今日”。
2. 查看今日读经、你可见的查经聚会、教会聚会、活动提醒，以及明确分配给你的个人服事事项。
3. 需要详情时，打开对应链接。
4. 需要完整列表时，进入对应页面：读经、查经、代祷、教会聚会、活动、公告、日历、我的服事或个人资料。

## 你可以做什么

- 在“读经”跟随读经计划，打开经文，并完成打卡。
- 在“查经”查看你可见的聚会和预备内容。
- 在“代祷”按页面规则阅读、发布、更新和回应代祷事项。
- 在“日历”查看你可见教会事项的只读日期视图。
- 在“教会聚会”查看你可见的正式教会聚会。
- 在“活动”浏览社区或团契活动，并表达参加意向。
- 在“公告”阅读正式教会沟通内容。
- 在“个人资料”维护账号基本资料和语言偏好。

## 怎么操作

### 今日

想快速查看现在需要留意的事项时，打开“今日”。这里可能显示读经、聚会、查经、活动提醒、公告和个人服事事项。需要详情时，请打开对应链接。

### 读经

打开“读经”，选择当前计划，阅读经文，读完后使用打卡操作。如果“今日”链接到读经事项，也会回到同一套读经流程。

### 查经

打开“查经”，选择可见聚会，阅读聚会详情和可用的预备内容。看到某个查经聚会，只表示你可以查看，不表示你自动拥有该聚会的服事角色。

### 代祷

打开“代祷”，选择代祷事项，并使用可用操作，例如已祷告、评论、编辑或举报。请按页面显示的隐私和可见范围操作。

### 日历

打开“日历”，选择月份或日期。日历是只读页面；它不会发布、编辑、排班、确认或取消任何事项。

### 教会聚会

打开“教会聚会”，选择可见聚会。看到聚会只表示你可以查看，不表示你被安排服事。

### 活动

打开“活动”，选择已发布且你可见的活动；只有计划参加时才报名。报名表示参加意向，不是服事安排。

活动开始前，只要活动仍然发布，你可以取消自己的有效报名。取消会立即生效，不需要组织者或同工批准。系统会保留报名历史，但你的取消会释放名额。

活动开始前，如果该活动仍然对你开放且还有名额，你可以重新报名。如果活动已满员，新的报名或重新报名都不可用。活动开始后，普通报名状态会冻结。当前活动版本没有候补名单。

### 公告

打开“公告”，阅读当前有效且你可见的正式沟通。重要公告也可能显示在“今日”。

### 个人资料 / 账号菜单

打开账号菜单，选择“个人资料”，更新可用资料。账号菜单也包含“帮助中心”、语言选项，以及在你可使用时显示的“我负责的单位”。

## 这不代表什么

- 看见某个活动不代表你被安排服事。
- 看见某个查经聚会不代表你拥有查经服事角色。
- 归属在某个教会结构单位不代表你拥有负责权限、同工权限或服事安排。
- 活动报名只表示参加意向。
- 日历是只读页面。
- 今日是日程，不是完整服事工作区。

## 疑难处理 / 下一步

如果你找不到预期事项，请先查看对应功能页面，并确认该事项是否应该对你的范围可见。如果你认为归属、可见性或语言设置不正确，请联系教会同工。
